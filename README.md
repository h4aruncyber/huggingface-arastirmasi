# Hugging Face Model Research

## Proje Hakkında

Bu proje, staj kapsamında Hugging Face platformunda yer alan popüler yapay zekâ modellerinin araştırılması amacıyla hazırlanmıştır.

Bu çalışmada DistilBERT modeli kullanılarak Python ile duygu analizi uygulaması geliştirilmiştir.

---

## Kullanılan Teknolojiler

- Python 3.11
- Hugging Face Transformers
- PyTorch
- Git
- GitHub
- Visual Studio Code

---

## Kurulum

```bash
python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python main.py
```
